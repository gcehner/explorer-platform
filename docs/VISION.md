# Vision

Explorer Platform is a personal MTB platform for documenting and publishing technical descriptions of mountain-bike tours.

It is focused on curated MTB rides.

Each tour combines structured information with maps, GPX tracks, elevation profiles and photography.

## What it is

Explorer Platform is a personal tour guide.

Its purpose is to organize outdoor adventures into clear, searchable and reusable technical guides.

## What it is not

Explorer Platform is not:

* a training platform
* a social network
* a travel diary

It does not replace Garmin Connect, Strava or Komoot.

## Core idea

Garmin Connect and GPX files provide raw activity data.

Explorer Platform enriches those activities with structured information such as:

* route description
* access information
* technical difficulty
* terrain
* elevation profile
* GPX track
* photos
* recommendations
* useful notes

## Long-term direction

The platform should eventually support:

* admin panel
* multiple users
* public and private tours
* AI-assisted content
* additional import sources
